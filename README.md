# CrossPoint Reader Fork

Adds the following:

- Easier WiFi setup: drop a `wifi.json` file in the shape of [`wifi.example.json`](./docs/wifi.example.json) at the root of your SD card to avoid the pain of typing
- [Readeck support](./docs/readeck.md): download tagged articles from your Readeck instance

Vibe coded because there is no way I'm writing C++ for free. Use at your own risk.
